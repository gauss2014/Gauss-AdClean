The builder extracts schema definitions only. The upstream network/client bootstrap
is not present in the published bundle. Ad-only logic preserves the original
Gauss filtering scope; UMP transport handling is added separately.

The separate build-enhance.cjs uses the same pinned source for the YouTube
API response handlers. It omits upstream HTTP/client adapters and uses a
local QX wrapper for captions, PiP, background playback, guide and settings.
Rebuild and verify with node build-enhance.cjs and node test-enhance.cjs.

googlevideo (MIT), fflate (MIT), brotli.js (MIT; decoder Google Apache-2.0),
